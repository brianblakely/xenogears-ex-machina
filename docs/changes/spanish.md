- The game's text can now be read in Spanish: choose **Settings → Gameplay → Language → Game text → Español**. Dialogue, narration, item and ability names and descriptions, shop, save and battle messages and place names read as [Romhack Hispano](https://xenogears.romhackhispano.org/)'s translation has them, with ñ, ¡ and ¿ drawn from the game's own font; the menus' command words are drawn in Spanish too.
