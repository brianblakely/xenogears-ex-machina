# The letters French adds to the game's font (docs/runtime.md, Languages).
# The port composes each from a letter of the player's own font (directory
# (0, 1) file 6) and an accent drawn here for this project (MIT, like the
# rest of this repository): no glyph of the original is copied.
#
# A glyph's rows are the font's 11 rows of 12 columns (row 0 the top; small
# letters span rows 3-9, capitals 1-9, descenders reach row 10).
#
#   accent <name> <row>=<columns 0-4, # drawn> ...
#   <char> <base letter> <accent> [drop=<rows>] [clear=<rows>]
#
# drop= takes those rows out of the base letter and moves the rows above them
# down (a capital, shortened to rows 3-9, leaves room for its accent);
# clear= blanks rows (the dot of i). A letter another language adds too is
# drawn alike (pt-BR/glyphs.txt): its code is the same in every language.
# The game draws each as a narrow letter. French writes oe for the ligature
# the font lacks (coeur, soeur).
