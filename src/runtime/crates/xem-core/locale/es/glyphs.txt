# The letters Spanish adds to the game's font (docs/runtime.md, Languages).
# The port composes each from a letter of the player's own font (directory
# (0, 1) file 6) and a mark drawn here for this project (MIT, like the rest
# of this repository): no glyph of the original or of Romhack Hispano's
# patch is copied. A letter another language adds too is drawn alike
# (pt-BR/glyphs.txt, fr/glyphs.txt, en-x-pw/glyphs.txt): its code is the
# same in every language.
#
# A glyph's rows are the font's 11 rows of 12 columns (row 0 the top; small
# letters span rows 3-9, capitals 1-9, descenders reach row 10).
#
#   accent <name> <row>=<columns 0-4, # drawn> ...
#   <char> <base letter> <accent> [drop=<rows>] [clear=<rows>]
#
# The inverted marks are drawn whole on the font's space: ¡ a dot above a
# stem that reaches below the line, ¿ a question mark turned over.

accent acute 0=...#. 1=..#..
accent tilde 0=.##.# 1=#..#.
accent diaeresis 1=.#.#.
accent tail 9=..#.. 10=.#...
accent inverted-exclamation 3=..#.. 5=..#.. 6=..#.. 7=..#.. 8=..#.. 9=..#.. 10=..#..
accent inverted-question 3=..#.. 5=..#.. 6=..#.. 7=.#... 8=#...# 9=#...# 10=.###.
