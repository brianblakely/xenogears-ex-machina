# Substitute glyphs for the PS1 BIOS's Kanji font, which save titles are
# drawn from (slot39 menu_save_title_render through Krom2RawAdd). Without
# the player's BIOS image the runtime places these where Krom2RawAdd finds
# its glyphs (xem_core::bios), and every other character stays blank.
#
# They cover what North American Xenogears save titles hold: the full-width
# space, the full-width digits and Latin letters, and the punctuation the
# titles use (． ！ ／ ’ −). README.md says how that set was found.
#
# Drawn for Xenogears Ex Machina; licensed with the project under the MIT
# licence (LICENSE). Nothing here comes from a BIOS or another font.
#
# Each glyph: its Shift-JIS code in hexadecimal and the character, then the
# BIOS's 16x15 cell, one row a line, '#' a set pixel and '.' a clear one.
# The file screen narrows each cell to 12 columns (it merges columns 1-2,
# 5-6, 9-10 and 13-14) and reads one row past it, which is why the top row
# stays clear.
